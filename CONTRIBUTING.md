# Contributing

Bug reports in Arabic or English are welcome. Include your OS, Inkscape version, extension name, exact steps and a small SVG that reproduces the problem. Remove private artwork before attaching it.

For code changes, describe the behavior before and after, keep the existing extension IDs and saved parameter names compatible, and run the relevant tests in [Development](docs/DEVELOPMENT.md). Generated release archives belong in GitHub Releases. Keep editable example SVGs and their generators in the repository.

Preserve existing copyright and third-party license notices. Pull requests should explain any new dependency or compatibility change.
