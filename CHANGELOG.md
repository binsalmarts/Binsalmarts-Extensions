# Changelog

## Suite 1.0.0 — 2026-11-01

- First complete public suite: ASCII Art Pro 1.2.0, Page Numbering Pro 1.2.0, Modern Grid 4.4.0, Artboard Maker Pro 1.0.0, Logo Export Pro 2.0.0, Logo Construction 1.0.0, Blend Tool Pro 1.1.0 and Vector Effects Pro 1.2.0.
- Separate Studio Dark Compact 2.3 theme package for macOS, with upstream licenses.
- Editable SVG examples for every extension, including four new Modern Grid examples.
- Arabic installation guide, example gallery, contribution guide and issue templates.
- Deterministic release archives, SHA-256 checksums and automated validation/release workflows.

Component versions retain their existing numbering; 1.0.0 identifies the combined suite release.
